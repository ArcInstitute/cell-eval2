# cell-eval2

Evaluation package for the Virtual Cell Challenge 2026 (`vcc2026`) — a GPU-accelerated
reimplementation of [`cell-eval`](https://github.com/ArcInstitute/cell-eval).

## The metric specification

**[The vcc2026 Metric Suite](docs/vcc2026_metrics/vcc2026-metrics.md)** — the six scored metrics,
how each is computed, and how they are combined into one score. Also available as a
[PDF](docs/vcc2026_metrics/vcc2026-metrics.pdf).

This is the document to read if you are preparing a submission. It is the specification the
competition is scored under.

## The code

The evaluation package itself lands here shortly, at its frozen competition release. Until then
this repository carries the specification only.
